## Ministry of Youth Strategic Plan Dashboard (Power BI)

### Overview

This project presents an interactive dashboard built using Microsoft Power BI to visualize and analyze the Ministry of Youth Strategic Plan data. The dashboard is designed to support decision-making by transforming strategic indicators into clear, interactive insights.

### Objectives

* Monitor key performance indicators (KPIs) of youth strategic initiatives
* Track progress against strategic goals
* Enable data-driven decision-making for stakeholders
* Provide interactive filtering and drill-down analysis

### Tools & Technologies

* Microsoft Power BI
* Excel (data preparation)
* Data modeling & DAX measures
* Data visualization techniques

### Dashboard Features

* KPI overview cards (progress, completion rates, targets)
* Trend analysis over time
* Regional / category-based segmentation
* Interactive filters and slicers
* Drill-through analysis for detailed insights

### Data Processing

* Data cleaning and transformation performed before visualization
* Structured dataset aligned with strategic indicators
* Relationships defined between key tables for modeling

### How to Use

1. Download the `.pbix` file from the repository
2. Open it using Microsoft Power BI Desktop
3. Refresh the dataset if needed
4. Use filters and slicers to explore insights

### Key Insights Delivered

* Progress tracking of strategic initiatives
* Identification of underperforming areas
* Performance comparison across categories
* Data-backed evaluation of strategic objectives

### Requirements

* Power BI Desktop installed
* Latest dataset version (Excel/CSV)
